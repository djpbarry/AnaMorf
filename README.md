# AnaMorf

AnaMorf is a [FIJI/ImageJ](https://fiji.sc) plug-in for analysing the morphology of filamentous structures (e.g. fungal hyphae). Given a directory of images, it segments each image, traces each object, and writes tabulated morphology data (projected area, circularity, total length, endpoints, branchpoints, hyphal growth unit, lacunarity, box-counting and Fourier fractal dimensions, curvature).

For installation and usage, see the [documentation](https://anamorf.readthedocs.io/en/development/).
