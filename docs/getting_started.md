# Getting started

## Installation

Install AnaMorf through the Fiji updater. Follow the instructions for
[following a third-party update site](https://imagej.net/update-sites/following)
and enable the **CALM** update site. This keeps AnaMorf and its IAClassLibrary
dependency up to date automatically.

AnaMorf 4.x requires Fiji to run on **Java 21**.

For building AnaMorf from source, see the *Developer guide*.

## Running AnaMorf

1. Start Fiji.
2. Select **Plugins > AnaMorf > AnaMorf Batch Processor**.
3. Set the parameters in the dialog (see the *User guide*).
4. Click **OK** and choose the directory containing the images to analyse.

Results are written to a results directory next to the input images (see the
*User guide*).
